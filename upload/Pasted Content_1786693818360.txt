# MASTER BUILD PROMPT

## Free Omnichannel WhatsApp + Telegram + SMS + Email Broadcasting Platform

Build a complete, production-ready, modern web application for omnichannel customer communication and broadcasting.

The application must allow users and organizations to manage contacts, create campaigns, broadcast messages through WhatsApp, Telegram and SMS, manage correspondence, receive replies, schedule campaigns, configure notifications, send email notifications, view analytics, create automations, and manage everything from a professional dashboard.

The application should be designed as a **free/open-source/self-hostable platform**.

The software itself must not charge users. However, the application must support official third-party communication APIs where the underlying provider may charge for WhatsApp, SMS, email, hosting, etc.

Do NOT implement unofficial WhatsApp Web automation, WhatsApp account scraping, QR-session abuse, spam evasion, or methods designed to bypass Meta/Telegram/SMS provider restrictions.

Use official APIs and provider integrations.
